How To Use Our Agents

Individual Agent Commands

Each agent can be used individually with the !dose command to generate specific credentials:

  • !dose identity

    Generates a full identity with Heroin Harry

  • !dose card visa

    Generates a Visa card with Meth Mandy

  • !dose phone

    Creates a virtual phone number with Xanny Xan

  • !dose email

    Provides a disposable email with Cocaine Carl

Combined Agent Commands

For a complete trial generation experience, use these commands:

  • !hit netflix

    Generates a complete Netflix trial with all agents

  • !hit https://example.com/trial

    Creates a trial for any custom URL provided

  • !trip https://example.com/trial

    Runs just Shroomy Sal's automation on a custom URL

  • !stash

    View all your generated trials and credentials

All commands can be used in our Discord server or directly through this website. Your trials are synchronized across both platforms.
