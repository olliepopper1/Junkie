# Trial Junkie Discord Bot - Test Plan

This document outlines the comprehensive test plan for the Trial Junkie Discord bot, designed to verify all functionality from subscription plan selection through trial registration and automation.

## Test Environment Setup

1. Ensure the Discord bot is running with the `discord_bot` workflow
2. Verify the following environment variables are properly configured:
   - `DISCORD_BOT_TOKEN`
   - `RAPIDAPI_KEY`
   - `SOLANA_WALLET_ADDRESS`
   - `DATABASE_URL` (if using PostgreSQL)

## Test Cases

### 1. Bot Connection and Basic Commands

- [ ] **Verify Bot Online**: Bot appears online in Discord
- [ ] **Verify Help Command**: `!help` displays available commands
- [ ] **Verify Agents Command**: `!agents` displays all available agents
- [ ] **Verify Quote Command**: `!quote harry` displays a random Heroin Harry quote

### 2. Subscription Plans and Payment Flow

- [ ] **Verify Plans Display**: `!plans` displays all available subscription tiers
- [ ] **Verify Free Plan**: `!pay one_time_hit` initiates free tier
- [ ] **Verify Payment Command**: `!pay five_dollar_rush` displays payment instructions with SOL wallet address
- [ ] **Verify Payment Verification**: `!verify_payment` or `!verify_payment <tx_id>` properly handles payment verification
- [ ] **Verify Payment Status**: `!payments` displays payment history
- [ ] **Verify Tier Command**: `!tier` displays current subscription tier

### 3. Credential Generation

- [ ] **Verify Identity Generation**: `!dose harry gmail` generates identity credentials
- [ ] **Verify Card Generation**: `!dose mandy amazon` generates payment card credentials
- [ ] **Verify Email Generation**: `!dose xan netflix` generates email credentials
- [ ] **Verify Phone Generation**: `!dose phone hulu` generates phone credentials

### 4. Service Trial Generation (Predefined Services)

- [ ] **Verify Netflix Trial**: `!hit netflix` generates credentials and profile for Netflix
- [ ] **Verify Hulu Trial**: `!hit hulu` generates credentials and profile for Hulu
- [ ] **Verify Spotify Trial**: `!hit spotify` generates credentials and profile for Spotify
- [ ] **Verify Disney+ Trial**: `!hit disney` generates credentials and profile for Disney+
- [ ] **Verify Amazon Prime Trial**: `!hit amazon` generates credentials and profile for Amazon

### 5. Universal Service Automation (Any Trial Website)

- [ ] **Verify Custom URL Registration**: `!trip url https://www.example.com/trial` registers a new website
- [ ] **Verify Custom Service Trial**: `!hit example` (after registering via URL) generates credentials
- [ ] **Verify Trial Automation**: `!trip example` runs automation script on the registered service
- [ ] **Verify Service Access**: Credentials for registered custom services are accessible via `!stash`

### 6. Data Management

- [ ] **Verify Stash Command**: `!stash` displays all generated credentials
- [ ] **Verify Rehab Command**: `!rehab` clears all user data when confirmed

## Integration Test Flow

1. Start with `!plans` to view subscription options
2. Use `!pay junkified` to simulate payment for premium plan
3. Use `!verify_payment` to confirm payment
4. Use `!hit netflix` to generate credentials for Netflix
5. Use `!trip netflix` to simulate the automation process
6. Use `!trip url https://customservice.com` to register a custom trial service
7. Use `!hit customservice` to generate credentials for the custom service
8. Use `!stash` to verify all generated credentials are saved
9. Use `!tier` to verify subscription tier
10. Use `!rehab` to clean up all test data

## API Integration Tests

- [ ] **Verify RapidAPI Integration**: All credential generation endpoints return valid data
- [ ] **Verify Solana Wallet Integration**: Payment address and verification function correctly

## Test Automation

Manual testing through Discord interface is required for initial verification. Future improvements may include automated testing using a Discord bot testing framework.

## Test Completion Criteria

All test cases must pass with the expected output, including:
- Successful credential generation
- Successful service registration and automation
- Proper payment flow handling
- Correct data storage and retrieval via stash

## Notes

- This is a simulated environment - no actual trials are created
- No real billing occurs during testing
- API keys must be properly configured for testing external integrations
