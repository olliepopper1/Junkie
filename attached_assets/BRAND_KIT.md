# Trial Junkies Brand Kit - Updated

## Brand Overview

Trial Junkies is an edgy, dark-themed brand focused on automating free trials through AI bots. The brand identity revolves around skeleton characters with a rebellious, underground aesthetic that appeals to tech-savvy users looking to maximize value from subscription services.

## Brand Elements

### Logo Variations

1. **Primary Logo**: Flaming skull in black hoodie (new official logo)
   - Used in website header, footer, and all primary branding
   - Represents the rebellious, underground nature of the brand
   - Color scheme: Orange flames, black hoodie, off-white skull

2. **Secondary Logo**: Skeleton movie theater scene
   - Used for testimonials and community imagery
   - Represents the collective experience of Trial Junkies users
   - Color scheme: Neon pink/blue, off-white skeletons

3. **Character Logos**: Individual skeleton characters
   - Used to represent different agents/bots
   - Each with unique color schemes and personalities

4. **Icon Only**: Skull icon for favicon and small applications

5. **Text Only**: "TRIAL JUNKIES" logotype for text-only applications

### Color Palette

- **Primary Colors**:
  - Burnt Orange: #FF5500 (RGB: 255, 85, 0)
  - Off-White: #F5F5F5 (RGB: 245, 245, 245)
  - Black: #000000 (RGB: 0, 0, 0)

- **Secondary Colors**:
  - Neon Pink: #FF00FF (RGB: 255, 0, 255)
  - Neon Blue: #00FFFF (RGB: 0, 255, 255)

### Typography

- **Headings**: Bebas Neue (Bold)
- **Body Text**: Roboto (Regular, Bold, Black)
- **Accents**: Roboto Mono (for code and technical elements)

### Imagery Style

- Dark backgrounds with high contrast elements
- Skeleton characters as brand mascots
- Neon/glowing effects for emphasis

## Usage Guidelines

### Do's
- Use official color codes for all brand materials
- Maintain character personalities in communications
- Keep the edgy, underground aesthetic consistent
- Use proper typography for all text elements
- Incorporate movie theater and entertainment themes where appropriate

### Don'ts
- Don't use characters in inappropriate contexts
- Don't alter character personalities or appearances
- Don't use bright, cheerful colors that clash with brand
- Don't present the brand as mainstream or corporate
