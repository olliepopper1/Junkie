### 1. **Personator API (Identity Verification)**

#### **Base URL**:  
`https://personator.melissadata.net/v3/WEB/ContactVerify/doContactVerify`

#### **Required Parameters**:
- **userID**: Your account or user ID.
- **authToken**: Your authentication token or API key (generated when you sign up for the API).
- **email**: The email to verify.
- **address** (optional): The address to verify.

#### **Request Example**:
```bash
curl --request GET \
  --url 'https://personator.melissadata.net/v3/WEB/ContactVerify/doContactVerify?authToken=YOUR_AUTH_TOKEN&email=email@example.com' \
  --header 'Content-Type: application/json'
```

#### **Headers**:
- `Authorization`: `Bearer YOUR_AUTH_TOKEN`
- `Content-Type`: `application/json`

#### **Notes**:
- Make sure to replace `YOUR_AUTH_TOKEN` with the actual API key you received when signing up for the service.
- Depending on the verification type, you might need to send extra data (e.g., phone number, address).

### 2. **Virtual Number API (Phone Verification)**

#### **Base URL**:  
`https://api.nexmo.com/verify/json`

#### **Required Parameters**:
- **api_key**: Your Nexmo API key.
- **api_secret**: Your Nexmo API secret.
- **number**: The phone number to verify.
- **brand**: (Optional) The name of your company (appears in the SMS).

#### **Request Example**:
```bash
curl --request POST \
  --url 'https://api.nexmo.com/verify/json' \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data 'api_key=YOUR_API_KEY&api_secret=YOUR_API_SECRET&number=PHONE_NUMBER&brand=YOUR_BRAND'
```

#### **Headers**:
- `Content-Type`: `application/x-www-form-urlencoded`

#### **Notes**:
- Replace `YOUR_API_KEY` and `YOUR_API_SECRET` with your actual Nexmo credentials.
- Ensure the phone number is in international format (e.g., `+1234567890`).

#### **Required Parameters**:

### 4. **Fake Card API (Credit Card Generation)**

#### **Stripe Test Cards (for testing)**

#### **Base URL**:  
`https://api.stripe.com/v1/charges`

#### **Required Parameters**:
- **amount**: The amount for the transaction (in cents).
- **currency**: The currency for the payment (e.g., `usd`).
- **source**: The token for a test credit card (Stripe provides test tokens like `tok_visa`).

#### **Request Example**:
```bash
curl --request POST \
  --url 'https://api.stripe.com/v1/charges' \
  --header 'Authorization: Bearer YOUR_STRIPE_SECRET_KEY' \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data 'amount=500&currency=usd&source=tok_visa'
```

#### **Headers**:
- `Authorization`: `Bearer YOUR_STRIPE_SECRET_KEY`
- `Content-Type`: `application/x-www-form-urlencoded`

#### **Notes**:
- Use Stripe's [test card tokens](https://stripe.com/docs/testing#international-cards) for testing, like `tok_visa`, `tok_mastercard`, etc.
- `amount` is specified in **cents**, so 500 would be `$5.00`.
